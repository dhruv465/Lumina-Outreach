The document provides an onboarding guide for Twilio's Conversational Intelligence, which analyzes customer conversations using AI technologies.[1]

Key concepts covered include:
*   **Conversations**: Interactions between two or more parties that can be transcribed and analyzed.[1]
*   **Transcripts**: Represent transcribed conversations stored in the Conversational Intelligence historical log.[1] This includes post-interaction transcription (for recordings) and real-time transcription (for calls).[1]
*   **Language Operators**: AI-powered natural language understanding tasks that extract insights from conversations, suchs as sentiment analysis or topic detection.[1] These can be pre-built by Twilio or custom-created.[1]
*   **Intelligence Services**: Individual configurations for Transcripts and Language Operators, allowing organization and management of transcription and analysis tasks.[1]

The guide also details how to create an Intelligence Service, options for redacting Personally Identifiable Information (PII), and how to transcribe with Intelligence (Recordings and Real-Time Calls).[1] It explains how to import conversations, view completed transcriptions, set up webhooks for notifications, and integrate results into applications using the API or single-page applications.[1]
